# 《盲拍暗战》v1.2.0 更新计划

> 版本目标：**增强竞技深度 + 丰富社交协作 + 拓展内容消费**
>
> 目标发布日期：2026-07-19
> 预计开发周期：4 周

---

## 一、版本核心目标

### 1.1 竞技深度提升（重点）
- 🎯 **赛事参与度**：每周至少 1 场锦标赛
- 🎯 **团队协作目标**：50% 玩家加入团队战模式
- 🎯 **核心手段**：锦标赛系统 + 2v2 团队战 + 排名奖励

### 1.2 社交协作增强
- 玩家组队对战，共享资金池
- 团队技能机制：激励 / 护盾 / 洞察
- 团队积分排行榜

### 1.3 内容消费拓展
- 藏品交易市场（玩家间自由交易）
- 角色皮肤系统（5 种稀有度 + 套装）
- 市场经济闭环（手续费 / 供求机制）

## 二、详细功能清单

### 🔴 高优先级功能（第一周开发）

#### 功能 2.1 — 锦标赛系统（Tournament System）
**需求说明**：
- 单败淘汰制赛事，8 人或 16 人参赛
- 冠军 / 亚军 / 四强阶梯奖励
- 锦标赛历史记录，展示玩家参与轨迹
- 可参加锦标赛列表（按状态筛选）
- 对阵图可视化（Match Bracket）

**功能拆解**：
1. [x] TournamentSystem.lua — 锦标赛核心系统
   - 锦标赛状态管理（registration / grouping / in_progress / completed / cancelled）
   - 8 人 / 16 人赛事自动对阵表生成（Fisher-Yates 洗牌）
   - 比赛结果提交与晋级逻辑
   - 奖励配置表（冠军 / 亚军 / 四强 / 参赛奖）
   - serverCloud 持久化玩家历史记录

2. [x] 配置扩展（Config.lua）
   - `Config.Tournament` — 锦标赛配置表
     - MaxPlayers: 8 / 16 人可选
     - Rewards: { 冠军 = 10000, 亚军 = 5000, 四强 = 2000 }
     - EntryFee: 0（免费参赛，首周开放测试）
     - MatchRules: { 5 轮，5000 初始余额 }

3. [x] 对阵图生成算法
   - 第一轮自动配对（随机）
   - 胜者晋级，败者淘汰
   - 轮次自动递进（R1 → R2 → 半决赛 → 决赛）

4. [x] UI 集成（GameUI.lua）
   - 锦标赛入口面板
   - 可参加锦标赛列表
   - 对阵图展示
   - 历史记录页

**依赖项**：PlayerDataManager.lua, AuctionManager.lua

## 四、配置与架构优化

### 架构 4.1 — 系统间集成
**需求**：v1.2 新增系统需要与 v1.1 现有系统联动
**方案**：
- 锦标赛 ↔ 赛季系统：锦标赛胜场计入赛季经验
- 团队战 ↔ 好友系统：可邀请好友加入团队
- 交易市场 ↔ 藏品系统：市场藏品与收藏馆联动
- 皮肤系统 ↔ 成就系统：特定成就解锁皮肤

### 架构 4.2 — EventBus 扩展
**需求**：v1.2 新增事件类型
**方案**：
- 扩展 `scripts/Utils/EventBus.lua` 事件列表
  - `tournament_start`：锦标赛开局
  - `tournament_win`：锦标赛胜利
  - `team_join`：加入团队
  - `team_win`：团队战胜利
  - `trade_listing`：挂单交易
  - `trade_purchase`：购买交易
  - `skin_unlock`：皮肤解锁

### 架构 4.3 — 统一市场经济监控
**需求**：防止市场经济失控（通货膨胀 / 资源刷出）
**方案**：
- 市场每日交易总量监控
- 异常价格自动检测
- 大额交易人工审核提示

## 八、风险与应对

| 风险 | 影响 | 概率 | 应对方案 |
|------|------|------|---------|
| 市场经济失控（通胀 / 刷出） | 经济系统崩溃 | ⚠️ 中 | 5% 手续费回金币池 + 每日交易限额 + 异常价格冻结 |
| 团队战不平衡（强力组合） | 体验下降 | ⚠️ 中 | 团队技能每周平衡调整，首发期技能体验卡形式 |
| 锦标赛参赛人数不足 | 功能利用率低 | ⚠️ 中 | 前 2 周免费参赛 + 奖励加倍，吸引玩家试玩 |
| 皮肤系统美术资源不足 | 内容延期 | ✅ 低 | 首发期使用占位配置，资源后续迭代补全 |
| 多人网络同步问题复杂 | 功能质量下降 | ⚠️ 中 | 锦标赛 / 团队战第一版仅支持 AI 填充 + 2 人联机 |
| 开发时间不足 | 功能延期 | ⚠️ 中 | 按优先级裁剪：优先保证锦标赛 + 市场，延后团队战扩展功能 |
