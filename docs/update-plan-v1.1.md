# 《盲拍暗战》v1.1.0 更新计划

> 版本目标：**提升玩家留存 + 增强游戏深度 + 丰富社交体验**
>
> 目标发布日期：2026-07-19
> 预计开发周期：4 周

---

## 一、版本核心目标

### 1.1 玩家留存提升（重点）
- 🎯 **周活跃度目标**：从 v1.0 的基础提升 30%
- 🎯 **次日留存目标**：达到 45%+
- 🎯 **核心手段**：赛季系统 + 周挑战任务 + 成就扩展

### 1.2 游戏深度增强
- 新增 4 个角色 + 专属技能机制
- 新增 100 件藏品 + 2 个主题系列
- 新增游戏模式（限时活动）

### 1.3 社交体验丰富
- 好友系统 + 在线状态
- 自定义房间 + 邀请机制
- 房间聊天 + 表情扩展

## 二、详细功能清单

### 🔴 高优先级功能（第一周开发）

#### 功能 2.1 — 赛季系统（Season System）
**需求说明**：
- 每赛季持续 2 周
- 赛季等级 1-50 级，每级奖励
- 赛季通行证：免费奖励 + 付费奖励
- 赛季专属成就（5 个）
- 赛季结束清算与排行榜

**功能拆解**：
1. [ ] SeasonSystem.lua — 赛季核心系统
   - 赛季状态管理（活跃 / 未开始 / 已结束）
   - 赛季等级与经验值计算
   - 奖励表配置
   - 赛季进度持久化（serverCloud）

2. [ ] 配置扩展（Config.lua）
   - `Config.Seasons` — 赛季配置表
     - SeasonName: "第一赛季·初露锋芒"
     - Duration: 14 天
     - LevelCount: 50 级
     - ExpPerGame: { win = 50, lose = 20 }
     - Rewards: 每级奖励表

3. [ ] 赛季奖励配置（30 个免费 + 20 个付费）
   - 等级 1-10：基础金币奖励
   - 等级 11-20：解锁新藏品系列
   - 等级 21-30：解锁新角色体验卡
   - 等级 31-40：专属边框 / 头像框
   - 等级 41-50：传说藏品奖励

4. [ ] UI 集成（GameUI.lua）
   - 赛季面板入口
   - 赛季进度展示
   - 奖励领取动画

**依赖项**：AchievementSystem.lua, PlayerDataManager.lua
**预计工作量**：3 天

---

#### 功能 2.2 — 周挑战任务（Weekly Challenges）
**需求说明**：
- 每周 3 个挑战任务，难度递增
- 与每日任务区分：更高奖励、更长周期
- 每周一 00:00 自动刷新

**功能拆解**：
1. [ ] 扩展 DailyMissionSystem.lua → **MissionSystem.lua**
   - 重构为统一任务系统
   - 支持每日任务 + 周任务
   - 任务类型识别与分类处理

2. [ ] 周任务配置（Config.lua）
   - `Config.WeeklyMissions` — 周任务表
     - 挑战1：累计获得 5 场胜利
     - 挑战2：单局出价排名第 1 达 10 次
     - 挑战3：收集 3 件传说藏品

3. [ ] 任务进度追踪
   - 周任务独立进度存储
   - 更丰厚的奖励（500-2000 金币）

**依赖项**：DailyMissionSystem.lua, PlayerDataManager.lua
**预计工作量**：2 天

---

#### 功能 2.3 — 新角色 ×4（第二波角色）
**需求说明**：
- 新增 4 个角色，每个拥有独特主动技能 + 被动
- 角色平衡：不破坏现有 8 角色平衡
- 新机制：**合作被动**（特定角色组合触发）

**功能拆解**：
1. [ ] CharacterData.lua 扩展
   - 角色 9：**神秘收藏家**「洞察」
     - 主动：预知下一轮对手平均出价（±20%）
     - 被动：每局首次出价超时自动 +5%

   - 角色 10：**风险投资人**「豪赌」
     - 主动：本轮出价效果 ×1.5，但余额 -500
     - 被动：如果出价排名第 1，余额 +300

   - 角色 11：**心理学家**「读心」
     - 主动：窥探某玩家当前余额（±1000）
     - 被动：被技能命中时自动反制一次

   - 角色 12：**时间管理大师**「时停」
     - 主动：本轮自己时限延长 10 秒
     - 被动：每局自动获得 1 次时限延长

2. [ ] 合作被动机制（新增）
   - 角色 1+2 同时在场：「经典组合」双方余额 +500
   - 角色 9+11 同时在场：「情报网」信息精度 +10%

3. [ ] CharacterSystem.lua 扩展
   - 合作被动检测逻辑
   - 新技能合法性校验

**依赖项**：CharacterData.lua, CharacterSystem.lua
**预计工作量**：3 天

## 四、配置与架构优化

### 架构 4.1 — 系统管理器（SystemManager）
**需求**：当前各系统独立初始化，缺乏统一管理
**方案**：
- 新增 `scripts/Game/SystemManager.lua`
- 统一初始化所有系统
- 系统间依赖管理
- 统一事件分发机制

### 架构 4.2 — 事件系统（EventBus）
**需求**：系统间耦合度较高（如成就系统直接调用结算流程）
**方案**：
- 新增 `scripts/Utils/EventBus.lua`
- 发布-订阅模式
- 标准事件：`game_start`, `round_end`, `game_end`, `bid_submit`

### 架构 4.3 — 配置热更新支持
**需求**：调整数值需要重启
**方案**：
- 配置加载函数支持重新加载
- 开发环境下自动检测配置变更

## 八、风险与应对

| 风险 | 影响 | 概率 | 应对方案 |
|------|------|------|---------|
| 赛季系统设计过于复杂 | 延期 1 周 | ⚠️ 中 | MVP 方案：仅保留等级 + 奖励，延后付费通行证 |
| 新角色平衡难以控制 | 影响游戏体验 | ⚠️ 中 | 新角色首发期为体验卡形式，可随时调整 |
| 自定义房间网络同步问题 | 功能质量下降 | ⚠️ 中 | 第一版仅支持 AI 填充 + 2 人联机 |
| 性能问题（藏品列表） | 用户体验下降 | ✅ 低 | 虚拟列表方案已在规划中，可快速实施 |
| 开发时间不足 | 功能延期 | ⚠️ 中 | 按优先级裁剪：优先保证赛季/周任务，延后社交功能 |
